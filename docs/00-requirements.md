# 1. 背景与目标

AI 编程博主需要第一时间获知大模型、AI 编程工具与开源生态的动态。当前依赖人工搜索，存在漏看、滞后、重复劳动。本项目做一个**本地优先、免费、可被其他 AI 复用**的热点雷达：

- 自动发现关键词相关的新内容，并推送；
- 每 30 分钟自动搜集指定范围（如「AI 编程」）内的热点，供人工浏览；
- 网页版验收通过后，封装为 Agent Skill，供其他 AI 调用；
- 全流程使用免费数据源，邮件使用 Ethereal 测试箱（后续可切 163 真实投递）。

# 2. 角色与场景

| 角色 | 场景 |
|---|---|
| 博主本人 | 添加关键词「GPT-5.2」，30 分钟内收到页面弹窗与邮件 |
| 博主本人 | 早上打开「热点」页，看过去 24h 的 AI 编程热点，按可信度/热度排序 |
| 其他 AI（Claude Code 等） | 通过 Skill 执行「加监控 → 扫描 → 汇总今日热点」 |
| 维护者 | 在设置页看各源健康度、今日用量、邮件投递记录 |

# 3. 功能需求

| 编号 | 需求 | 验收要点 |
|---|---|---|
| FR-01 | 关键词监控：新增/编辑/停用/删除关键词，支持别名与排除词 | 关键词与别名均可命中；排除词生效 |
| FR-02 | 范围热点：内置「AI 编程 / 大模型发布 / 开源模型」三个 Topic，可编辑查询词 | 每个 Topic 独立周期与阈值 |
| FR-03 | 多源采集：HN、Bing News RSS、官方 RSS、sitemap 爬虫、中文媒体 RSS、arXiv、GitHub Releases；X 适配器默认关闭 | 至少 4 类源同时入库；单源失败不影响整体 |
| FR-04 | 去重与聚类：URL 规范化、平台 ID、标题相似度、事件聚合 | 同一事件多源报道只生成一个事件 |
| FR-05 | 规则核验：来源权重、独立域名印证、传闻词、高仿账号/仿冒域名 | 未证实内容进观察区，不推送 |
| FR-06 | 页面弹窗：Toast、高优先 Modal、未读中心、标题未读数 | SSE 1 秒内到达；刷新后可补看未读 |
| FR-07 | 邮件通知：合并窗口、事件去重、频率上限、Ethereal 预览链接 | 邮件可预览；失败重试并记录 |
| FR-08 | 立即扫描：手动触发全部或单个 Watch/Topic | 不等待 30 分钟周期 |
| FR-09 | 事件详情：标题、源摘要、来源列表、独立域数量、判定理由、原文链接 | 证据链可追溯 |
| FR-10 | 运维可见：各源最后成功时间、失败次数、今日请求量 | 状态页可查 |
| FR-11 | 反馈：标记误报/漏报，写入 feedback 表 | 不改变历史判定，仅记录 |
| FR-12 | Agent Skill：SKILL.md + CLI，复用同一套核心逻辑 | 另一 AI 会话可完成「加词→扫描→汇报」 |
| FR-13 | 配置：`.env` + 设置页；密钥只读环境变量 | 页面不回显任何密钥 |
| FR-14 | 降级：X 未配置、GDELT 不可达、邮件失败、AI 未配置均不阻塞主流程 | 状态页给出明确原因 |

# 4. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 本机冷启动 < 2s；`/api/hotspots` P95 < 300ms（1 万条量级）；页面首屏 < 1.5s |
| 容量 | 每天 1,000–3,000 条入库；SQLite 单文件 < 200MB/月 |
| 时效 | 采集周期 30 分钟；SSE 推送延迟 < 1s；邮件合并窗口 120s |
| 可用性 | 单源失败自动退避；连续失败 3 次标记 unhealthy；服务崩溃重启后从游标续跑 |
| 安全 | 默认绑定 `127.0.0.1`；`HOST=0.0.0.0` 时必须设置 `ACCESS_TOKEN`；AI/SMTP/X 密钥不出服务端 |
| 隐私 | 只存标题、短摘要、链接、公开互动数；不存正文、不存图片、不存用户隐私 |
| 合规 | 遵守 robots.txt；搜索引擎结果只使用 RSS 形态；X 仅通过授权 API |
| 可访问性 | 对比度 ≥ 4.5:1；键盘全流程；44×44 触控；`prefers-reduced-motion` 生效 |
| 兼容 | Chrome/Safari/Edge 最近两个大版本；375px 起无横向滚动 |

# 5. 范围外（本期不做）

- AI 真伪判定与摘要（OpenRouter 未配置；当前为规则核验，AI 层延期）
- 多用户、登录、权限
- 页面关闭后的系统级推送（仅邮件）
- 全文抓取、图片/视频下载、转载
- X 的付费长期采集（仅保留适配器与试用开关）
- 搜索引擎 HTML 结果页抓取（DDG 实测验证码，Bing/Google robots 禁止）
- Google News RSS（robots 未允许）
- 移动 App、浏览器插件

# 6. 验收定义

1. 添加关键词后，30 分钟内（或点「立即扫描」）能对真实新内容产生页面弹窗与邮件预览链接；
2. 注入「未知小站声称 GPT-6 发布」的伪造条目：只进观察区，不弹窗、不发邮件；
3. 注入「官方博客 + 两家独立媒体」报道：判定 `verified` 并推送；
4. 同一事件重复采集 3 次，只弹一次、只发一封；
5. 375/768/1024/1440 四档宽度无横向滚动，键盘可完成「看列表 → 开详情 → 关详情」；
6. `npm test` 全绿；按 README 可从零跑通；
7. Skill 在另一 AI 会话中完成一次「加关键词 → 扫描 → 汇报」。

# 7. 术语

| 术语 | 含义 |
|---|---|
| Item | 单条采集结果（一篇文章、一条推文、一个 Release） |
| Event | 由多条 Item 聚类得到的同一事件 |
| Watch | 一个关键词监控规则 |
| Topic | 一个范围热点订阅（如「AI 编程」） |
| 独立域 | 排除 X、排除同标题转载后的不同注册域名 |
| 规则核验 | 不使用 AI，仅基于来源、印证、词表的可信度计算 |
| Ethereal | Nodemailer 提供的免费测试 SMTP，可生成邮件预览链接，不真实投递 |
