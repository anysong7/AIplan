# 1. 设计概念：编辑部 × 雷达控制台

不做"卡片瀑布 + 紫色渐变"的通用 AI 仪表盘。视觉语言取两件事：

- **报纸编辑部的排版秩序**：衬线标题、细线分栏、密集但克制的元数据；
- **雷达/示波器的信号感**：扫描线、同心环、信号强度条、可信度环。

关键词：墨黑、纸色、发丝线、单一强调色、等宽数字、无圆角滥用、无玻璃拟态、无 emoji 图标。

# 2. 设计 token

```css
:root {
  /* 底色 */
  --ink:        #0A0C0F;
  --panel:      #10151A;
  --panel-2:    #151C23;
  --line:       #1F2933;
  --line-strong:#2B3844;

  /* 文字 */
  --paper:      #E8E4DA;
  --paper-dim:  #B9B4A8;
  --muted:      #8A94A0;

  /* 信号色 */
  --signal:     #F2B01E;  /* 热点 / 扫描 */
  --verified:   #4ADE80;  /* 已核实 */
  --danger:     #E5484D;  /* 告警 / 疑似 */
  --watch:      #9CA3AF;  /* 观察区 */

  /* 语义 */
  --bg: var(--ink);
  --fg: var(--paper);
  --card: var(--panel);
  --border: var(--line);

  /* 排版 */
  --font-display: "Songti SC", "Noto Serif CJK SC", "Source Han Serif SC", Georgia, serif;
  --font-body: -apple-system, BlinkMacSystemFont, "PingFang SC", "Noto Sans CJK SC", "Microsoft YaHei", sans-serif;
  --font-mono: ui-monospace, "SF Mono", Menlo, Consolas, "Liberation Mono", monospace;

  /* 间距：4 的倍数 */
  --s1: 4px; --s2: 8px; --s3: 12px; --s4: 16px;
  --s5: 24px; --s6: 32px; --s7: 48px; --s8: 64px;

  /* 尺寸 */
  --rail-w: 304px;
  --aside-w: 360px;
  --topbar-h: 56px;
  --radius: 2px;         /* 几乎直角，编辑感 */
  --shadow: 0 1px 0 rgba(255,255,255,.04), 0 8px 24px rgba(0,0,0,.35);
}
```

- 亮色模式不做（个人工具，默认深色），但所有颜色走变量，后续可加 `[data-theme=light]`。
- 对比度：`--paper` 对 `--ink` ≈ 15:1；`--muted` 对 `--ink` ≈ 5.4:1；`--signal` 对 `--ink` ≈ 9:1。

# 3. 字体与排版

| 用途 | 字体 | 规格 |
|---|---|---|
| 事件标题 | display 衬线 | 20px/1.35，字重 600；桌面 22px |
| 页面大标题 | display 衬线 | 28px/1.2 |
| 正文/摘要 | body 无衬线 | 14px/1.7 |
| 元数据（时间/来源/分数） | mono | 11–12px，字距 0.04em，全大写英文 |
| 按钮 | body | 13px，字重 500 |

数字统一 tabular：`font-variant-numeric: tabular-nums`。

中英文混排：屏幕阅读顺序正常；标题不在中英文间强制加空格（由内容决定）。

# 4. 布局

## 桌面（≥1280px）

```
┌──────────────────────────────────────────────────────────────┐
│ TOPBAR  SIGNAL / 信号雷达   [搜索]   [立即扫描]   未读 3  设置 │
├───────────────┬──────────────────────────────────────────────┤
│ RAIL 280px    │ FEED 自适应                                  │
│ 雷达盘        │ Topic Tabs + 筛选条 + 事件卡片流             │
│ Watch 列表    │                                              │
│ 源健康摘要    │                                              │
│ 今日用量      │                                              │
└───────────────┴──────────────────────────────────────────────┘
                                     ▲ 详情：右侧 380px 抽屉覆盖
```

- 详情以抽屉覆盖在 feed 右侧，不挤压列表宽度；
- ≤1024px：隐藏 Rail，feed 全宽，抽屉 420px；
- ≤768px：单栏；底部 Tab（热点 / 监控 / 设置）；详情从底部滑入（92% 高度）；Toast 顶部居中。

## 移动端

- 顶栏保留：标题 + 未读 + 扫描按钮（44×44）。
- Topic Tabs 横向滚动，带渐隐边缘。
- 卡片间距 12px，整卡可点；右侧显示可信度环 36px。
- 底部 Tab 高 56px + 安全区 `padding-bottom: env(safe-area-inset-bottom)`。

# 5. 签名组件

| 组件 | 说明 |
|---|---|
| `ScanBar` | 顶栏下方 2px 扫描线，空闲 8s 缓扫；扫描时 1.2s 快速扫过；`reduced-motion` 下静止 |
| `RadarDial` | 160–200px 同心环 + 扫描扇形；每条新事件一个点（按可信度着色）；中心显示"今日 N 条"；点击触发全量扫描 |
| `HotspotCard` | 左侧 3px 信号条（热度），标题衬线，2 行摘要，底部来源 chips + 时间；右上可信度环 |
| `CredibilityRing` | SVG 圆环，0–100 分；颜色：≥85 绿、65–84 黄、<65 灰；中心数字 mono |
| `SignalBar` | 5 段式热度条，按 heat 分档点亮 |
| `EvidenceChain` | 来源按"一手/媒体/社区"分组，显示独立域数量与"已核实/较可信/未证实"徽标 |
| `DetailDrawer` | 事件详情：标题、摘要、评分拆解（来源 45%、印证 35%、传闻 20%）、条目列表、原文链接、反馈按钮 |
| `ToastStack` | 右上（移动端顶部），最多 3 条，含"查看"与关闭；悬停暂停计时 |
| `AlertModal` | 高优先事件；`role=alertdialog`，焦点陷阱，Esc 关闭 |
| `SourceHealth` | 圆点：绿/黄/红/灰；hover 显示最后成功时间与失败次数 |
| `Icon` | 内联 SVG（搜索、扫描、邮件、对勾、警示、关闭、外链、设置、雷达） |

# 6. 交互规范

## 快捷键

| 键 | 行为 |
|---|---|
| `/` | 聚焦搜索 |
| `j` / `k` | 下一条 / 上一条事件 |
| `Enter` | 打开当前事件详情 |
| `s` | 立即扫描 |
| `r` | 标记当前事件已读 |
| `?` | 快捷键帮助 |
| `Esc` | 关闭抽屉/弹窗；输入框内不拦截 |

输入框聚焦时禁用 `j/k/s`；快捷键在 `?` 帮助面板中可查。

## 弹窗

- Toast：4.8s 自动关闭；悬停/聚焦暂停；"查看"打开详情并标记已读；同一事件 24h 不重复。
- Modal：仅 `score ≥ 0.88` 且已核实；不自动关闭；主按钮"查看证据"，次按钮"知道了"。
- 未读：侧栏徽标 + `document.title = "(3) SIGNAL"`；进入对应视图后清零。
- 新条目：卡片左侧信号条 2s 脉冲（reduced-motion 下静态高亮）。

## 反馈

- 详情底部："误报" / "标题党" / "来源不可信" 三个按钮，写入 `feedback`，并 toast "已记录"。
- 设置页显示"最近反馈"，不做自动重训（规则模式无模型）。

# 7. 状态设计

| 状态 | 表现 |
|---|---|
| 首次启动（无数据） | 雷达盘静止、中心显示"雷达静默"；下方引导"添加第一个关键词"；右侧显示源健康 |
| 扫描中 | 扫描线加速、雷达扇形旋转、顶栏显示进度（已处理/总数） |
| 无新结果 | 列表保持，顶部一行"本轮无新增 · 12:30 再扫" |
| AI 未配置 | 不展示（本期无 AI）；设置页显示"AI 增强未启用"灰色项 |
| X 未配置 | 源健康面板显示"未配置"，不报错 |
| 邮件失败 | 通知中心红点 + 原因 + "重试"按钮 |
| 网络断线 | 顶栏"实时连接中断，正在重连"细条；恢复后自动补发 |
| 后端不可达 | 整页错误态，含"重试"与"查看日志路径" |

# 8. 动效

| 元素 | 时长/曲线 |
|---|---|
| Toast 进入 | 220ms `cubic-bezier(.2,.8,.2,1)` |
| 卡片插入 | 260ms 位移 8px + 透明度 |
| 抽屉 | 280ms 位移 |
| 扫描线 | 空闲 8s / 扫描 1.2s linear |
| 可信度环 | 600ms stroke-dashoffset 动画（首次渲染） |

全部在 `@media (prefers-reduced-motion: reduce)` 下关闭位移与旋转，仅保留透明度变化。

# 9. 无障碍

- 语义结构：`<header> <nav> <main> <article> <aside>`；
- 焦点可见：2px `--signal` outline + 2px offset；不使用 `outline: none`；
- 点击区 ≥44×44px；
- 图标按钮必须有 `aria-label`；纯装饰 SVG `aria-hidden="true"`；
- Toast 容器 `aria-live="polite"`；Modal `role="alertdialog" aria-modal="true"`，打开时焦点移入，关闭后归还触发元素；
- 颜色不是唯一信息载体：可信度同时有文字标签，来源类型同时有图标 + 文本；
- 键盘可完成：筛选 → 列表 → 详情 → 原文。

# 10. 邮件模板

- 亮色底 `#F7F4EC`，墨色文字，信号黄分隔线；单栏 600px；
- 头部：`SIGNAL` 字标 + 日期 + "已核实 N 条"；
- 每条：标题（衬线）、一句话摘要、可信度 + 独立域数 + 来源 chips、两枚按钮（阅读原文 / 在雷达中查看）；
- 底部：本轮统计、管理订阅链接（`http://127.0.0.1:8787/#/settings`）、"规则核验，非 AI 判定"声明；
- 纯文本版本同结构；不引用外部图片与字体；`prefers-color-scheme: dark` 仅做保守适配。
